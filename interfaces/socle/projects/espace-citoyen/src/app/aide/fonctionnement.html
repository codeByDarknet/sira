Comment ça marche

Plus besoin de fournir un papier que l’État a déjà. Rien ne part sans votre accord.

  1. Un service vous demande un accès. Il vous montre un QR code ou un code court, ou sa demande arrive ici.
  2. Vous lisez la demande : qui demande, quelles informations, pourquoi et pour combien de temps.
  3. Vous autorisez ou vous refusez. Si vous refusez, le service ne reçoit rien.
  4. Vous gardez la main. Vous voyez qui a consulté quoi, et vous pouvez retirer un accès à tout moment.

Ce que le service reçoit

  • Une réponse oui ou non (« vous êtes majeur »), sans l’information elle-même ;
  • quelques informations précises (nom, prénoms) ;
  • ou un document PDF (un extrait d’acte de naissance).

Le code du service

Pour autoriser depuis votre téléphone, recopiez le code à 6 chiffres affiché par le service. Si vous n’êtes pas devant ce service, refusez.

Quand une administration ne répond pas

Sira réessaie seul, sans rien vous redemander. L’historique montre ce qui a réussi et ce qui a échoué.
